## 📊 Employee Data Structure

Each employee profile includes:

| Field | Type | Required | Validation |
|-------|------|----------|-----------|
| **name** | string | ✓ | Min 2 chars, max 500 |
| **email** | string | ✓ | Valid email format |
| **phone** | string | ✓ | Valid phone (min 10 digits) |
| **department** | string | ✓ | Max 500 characters |
| **role** | string | ✓ | Max 500 characters |
| **hireDate** | string | ✓ | Format: YYYY-MM-DD |

Plus auto-managed timestamps:
- `createdAt` - Set when created
- `updatedAt` - Updated on modifications
- `id` - Auto-generated by Firestore

## 🚀 Quick Start

### Example API Calls

**Create an employee:**
```bash
curl -X POST http://localhost:5000/api/employees \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Dr. John Smith",
    "email": "john.smith@clinic.com",
    "phone": "+1-555-123-4567",
    "department": "Medical",
    "role": "Doctor",
    "hireDate": "2024-01-15"
  }'
```

**Get all employees:**
```bash
curl http://localhost:5000/api/employees
```

**Filter by department:**
```bash
curl "http://localhost:5000/api/employees?department=Medical"
```

**Update an employee:**
```bash
curl -X PUT http://localhost:5000/api/employees/emp-001 \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Dr. John Smith",
    "email": "john.smith@clinic.com",
    "phone": "+1-555-123-4567",
    "department": "Medical",
    "role": "Senior Doctor",
    "hireDate": "2024-01-15"
  }'
```

## ✨ Validation Examples

The backend automatically validates:

✓ **Email:** Requires valid format (e.g., john@example.com)
✗ Invalid: "john@invalid"

✓ **Phone:** Accepts various formats with 10+ digits
✗ Invalid: "123" (too short)

✓ **Date:** Must be YYYY-MM-DD format and valid date
✗ Invalid: "01/15/2024", "2024-02-30"

✓ **Name:** Minimum 2 characters
✗ Invalid: "J" (too short)
