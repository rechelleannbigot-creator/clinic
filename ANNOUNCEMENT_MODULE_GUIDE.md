# Announcement Management Module - Implementation Guide

## Overview
A complete, fully functional Announcement Management System for the Clinic Management System that allows Administrators to create, publish, and manage announcements for Students and Clinic Staff.

## Features Implemented

### 1. Admin Announcement Dashboard
- **Location**: `/admin/notifications` (via Admin Sidebar "Announcements" link)
- **Features**:
  - Summary cards showing:
    - Total Announcements
    - Published Announcements
    - Scheduled Announcements
    - Draft Announcements
  - Comprehensive announcements table with:
    - Announcement ID
    - Title
    - Category
    - Recipients
    - Priority level
    - Published date
    - Status badge
    - Action buttons
  - Search functionality
  - Filter by status (All, Published, Draft, Scheduled, Archived)
  - Professional, modern UI matching the existing design

### 2. Create/Edit Announcements
- Modal form with the following fields:
  - **Announcement Title** (required)
  - **Category** (dropdown):
    - General Announcement
    - Health Advisory
    - Clinic Schedule
    - Medical Reminder
    - Emergency Announcement
    - Important Notice
  - **Message** (textarea with rich text, required)
  - **Target Recipients** (checkboxes):
    - All Students
    - All Clinic Staff
    - Students Only
    - Clinic Staff Only
  - **Priority Level** (dropdown):
    - Normal
    - Important
    - Urgent
  - **Publication Option** (dropdown):
    - Save as Draft
    - Publish Immediately
    - Schedule Announcement
  - **Publication Date & Time** (datetime picker, if scheduled)
  - Attachment field (optional)
  - Form validation for all required fields

### 3. Announcement Management Actions
- **View**: Display complete announcement details in a modal
- **Edit**: Update draft announcements (title, message, recipients, category, priority)
- **Publish**: Convert drafts to published status
- **Schedule**: Set future publication date/time
- **Archive**: Move announcements to archived status
- **Delete**: Remove announcements with confirmation dialog
- **Status Tracking**: Draft → Published/Scheduled → Archived

### 4. Student Dashboard Announcements
- **Location**: `/student/announcements`
- **Features**:
  - Displays only announcements for "All Students" or "Students Only"
  - Shows unread notification badge with count
  - Announcement cards with:
    - Category badge with color coding
    - Title
    - Priority badge (if not Normal)
    - Preview of message (first 150 characters)
    - Published date
    - "Read More" button
  - Unread indicator (blue dot, pulsing animation)
  - Click to open full details modal
  - Mark as read automatically when opened
  - Automatic unread count update
  - Empty state when no announcements
  - Loading state
  - Error handling with retry capability

### 5. Clinic Staff Dashboard Announcements
- **Location**: `/staff/announcements`
- **Features**:
  - Displays only announcements for "All" or "Clinic Staff Only"
  - Identical UI to student version but filtered for staff recipients
  - Unread notification badge
  - Full announcement cards with metadata
  - Modal detail view
  - Automatic read status tracking
  - Empty state and loading states

### 6. Backend API Endpoints
All endpoints are secured with authentication middleware.

#### Admin Endpoints
- `POST /api/announcements` - Create announcement (admin only)
- `GET /api/announcements` - Get all announcements with optional status filter (admin only)
- `PUT /api/announcements/:announcementId` - Update announcement (admin only)
- `DELETE /api/announcements/:announcementId` - Delete announcement (admin only)
- `POST /api/announcements/:announcementId/publish` - Publish announcement (admin only)
- `POST /api/announcements/:announcementId/archive` - Archive announcement (admin only)

#### User Endpoints
- `GET /api/announcements/user/announcements` - Get user's visible announcements
- `GET /api/announcements/user/unread-count` - Get unread count for current user
- `POST /api/announcements/:announcementId/read` - Mark announcement as read
- `GET /api/announcements/:announcementId` - Get announcement details with access control

### 7. Database Structure
Firestore collections used:

**announcements** collection:
```javascript
{
  announcementId: string (auto-generated by Firestore)
  title: string
  category: string
  message: string
  recipients: array [strings]
  priority: string ('Normal', 'Important', 'Urgent')
  attachment: object (optional) | null
  status: string ('Draft', 'Published', 'Scheduled', 'Archived')
  createdBy: string (user UID)
  createdAt: timestamp
  publishedAt: timestamp (nullable)
  scheduledAt: timestamp (nullable)
  updatedAt: timestamp
}
```

**announcementReadStatus** collection:
```javascript
{
  userId: string (user UID)
  announcementId: string
  readAt: timestamp
}
```

### 8. Frontend Services
**File**: `src/services/announcementService.js`

Functions:
- `createAnnouncement(data)` - Create new announcement
- `getAllAnnouncements(status, limit)` - Get all announcements (admin)
- `getUserAnnouncements()` - Get announcements for current user
- `getAnnouncementUnreadCount()` - Get unread count
- `markAnnouncementAsRead(announcementId)` - Mark as read
- `getAnnouncementDetail(announcementId)` - Get full details
- `updateAnnouncement(announcementId, data)` - Update announcement
- `deleteAnnouncement(announcementId)` - Delete announcement
- `publishAnnouncement(announcementId)` - Publish announcement
- `archiveAnnouncement(announcementId)` - Archive announcement

### 9. Security & Access Control
- **Admin Access**: Only administrators (role = 'admin') can create, edit, delete, publish announcements
- **User Access**: Students and staff can only view announcements intended for them:
  - Students see: "All" + "Students Only"
  - Staff see: "All" + "Clinic Staff Only"
- **Backend Validation**: User roles are verified on the backend for all operations
- **Read Status Isolation**: Each user has independent read/unread status tracking

## How to Use

### For Administrators
1. Click "Announcements" in the Admin Sidebar (or navigate to `/admin/notifications`)
2. Click "+ Create Announcement" button
3. Fill in the announcement form:
   - Enter title and message
   - Select category
   - Choose recipients
   - Set priority level
   - Choose publication option
4. Click "Create" or "Update"
5. To publish a draft: Click "Publish Now" action button
6. To view details: Click "View" icon
7. To edit: Click "Edit" icon for draft announcements
8. To archive: Click "Archive" button on published announcements
9. To delete: Click "Delete" icon with confirmation

### For Students
1. Click "Announcements" in Student Dashboard/Sidebar (or navigate to `/student/announcements`)
2. View list of published announcements
3. See unread count badge at top
4. Click on any announcement to read full details
5. Details automatically mark announcement as read
6. Unread count updates automatically

### For Clinic Staff
1. Click "Announcements" in Staff Dashboard/Sidebar (or navigate to `/staff/announcements`)
2. View list of published announcements intended for staff
3. Same interaction as students
